☁️ Cloud Concepts (25–30% of exam)

IaaS — Infrastructure as a Service
Rent virtualised hardware. You manage OS, middleware, apps. Azure VMs, Azure Disk Storage. Most flexible, most responsibility.
PaaS — Platform as a Service
Managed platform; you deploy code, Azure manages infrastructure + OS. Azure App Service, Azure SQL Database, AKS. Focus on your app, not servers.
SaaS — Software as a Service
Fully managed application. Microsoft 365, Dynamics 365, Salesforce. No infrastructure management at all.
Public Cloud
Resources owned and operated by a cloud provider (Azure), delivered over internet. Shared hardware, pay-as-you-go, no capital expense.
Private Cloud
Cloud environment on-premises or hosted for a single organisation. Full control, higher cost. Azure Stack Hub enables on-prem Azure services.
Hybrid Cloud
Combines public and private cloud. Workloads move between environments. Azure Arc extends Azure management to any infrastructure.

Cloud Benefits

BenefitWhat it means
High AvailabilitySLA-backed uptime guarantees (99.9%–99.99%). Redundancy prevents single points of failure.
ScalabilityAdd resources as demand grows (vertical = bigger VM; horizontal = more VMs).
ElasticityAuto-scale up AND down with demand. Pay only for what you use.
AgilityProvision infrastructure in minutes vs weeks. Accelerate innovation.
Geo-distributionDeploy near users anywhere in the world. Reduce latency.
Disaster RecoveryReplicate workloads to secondary regions. Azure Site Recovery automates failover.

🔐 Identity & Security

Microsoft Entra ID (formerly Azure Active Directory) is Azure's cloud-based identity service. Every Azure subscription has one Entra ID tenant.

Authentication vs Authorisation
Authentication = Who are you? (verify identity). Authorisation = What can you do? (check permissions). Entra ID handles both.
Multi-Factor Authentication (MFA)
Something you know (password) + something you have (phone) + something you are (biometric). Dramatically reduces account compromise risk.
Conditional Access
Policy-based access. "If user is outside corporate network AND accessing sensitive app, require MFA." Zero Trust implementation.
RBAC (Role-Based Access Control)
Grant minimum necessary permissions. Built-in roles: Owner, Contributor, Reader. Custom roles possible. Applied at management group, subscription, resource group, or resource level.
Zero Trust Principles
Verify explicitly. Use least privilege access. Assume breach. Never trust, always verify — even inside the network perimeter.
Defence in Depth
7 layers: Physical → Identity → Perimeter → Network → Compute → Application → Data. Each layer protects against different attack vectors.

🏛️ Azure Governance & Management

Resource Hierarchy

🏢 Management Groups
↳ Apply policies and RBAC across multiple subscriptions
📋 Subscriptions
↳ Billing boundary + access control boundary
📁 Resource Groups
↳ Logical container for related resources (deploy, manage, delete together)
⚙️ Resources (VMs, databases, storage accounts…)
Azure Policy
Enforce organisational standards. E.g. "all resources must have a Cost Centre tag", "VMs may only be created in West Europe". Audit, deny, or remediate non-compliant resources.
Azure Blueprints
Package policies, RBAC assignments, and ARM templates together. Repeatable, compliant environment setup. Like a "template for a subscription".
Azure Cost Management
Monitor spend, set budgets, get alerts, analyse costs by resource/department. Integrate with Azure Advisor for cost optimisation recommendations.
Azure Advisor
Personalised recommendations across 5 categories: Cost, Security, Reliability, Operational Excellence, Performance. Free, always-on guidance.
Resource Locks
CanNotDelete or ReadOnly locks on resources, groups, or subscriptions. Prevent accidental deletion or modification.
Tags
Key-value metadata on resources. Essential for cost allocation, governance, automation. E.g. Environment:Production, Owner:TeamName.

💰 Pricing & SLAs (30–35%)

ConceptDetails
Pay-As-You-GoNo upfront commitment. Highest per-unit cost. Best for unpredictable workloads.
Reserved Instances1-year or 3-year commitment. Up to 72% savings vs PAYG. Best for steady-state workloads.
Spot VMsUse unused Azure capacity at up to 90% discount. Can be evicted with 30s notice. Non-critical batch workloads.
Azure Hybrid BenefitUse existing on-premises Windows Server / SQL Server licences in Azure. Significant savings.
Total Cost of Ownership (TCO)Azure TCO Calculator: compare on-premises vs Azure costs including hardware, software, power, facilities, IT staff.
SLA (Service Level Agreement)Azure guarantees uptime % per service. VMs: 99.9% single, 99.99% across AZs. Downtime calculation: 99.9% = 8.7h/year, 99.99% = 52min/year.
Composite SLA: When services depend on each other, multiply their SLAs. VM (99.9%) × SQL (99.99%) = 99.89%. Adding redundancy INCREASES composite SLA.
