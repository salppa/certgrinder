☁️ The 6 Advantages of Cloud Computing

1. Trade capital for variable expense
Pay only for what you consume. No massive upfront hardware investment. CapEx → OpEx.
2. Benefit from massive economies of scale
AWS aggregates usage from hundreds of thousands of customers → lower prices than you could achieve alone.
3. Stop guessing capacity
Scale up or down in minutes. No overprovisioning for peak, no underprovisioning for growth.
4. Increase speed and agility
New IT resources available in minutes, not weeks of procurement. Dramatically lowers cost of experimentation.
5. Stop spending money on data centres
Focus on customers and differentiating your business, not racking servers and cooling data centres.
6. Go global in minutes
Deploy to multiple AWS Regions with clicks. Serve users worldwide with low latency at minimal cost.

🔐 Shared Responsibility Model

The most important concept in AWS security. AWS and the customer each have distinct responsibilities.

AWS Responsible For (Security OF the Cloud)Customer Responsible For (Security IN the Cloud)
Physical data centre security (guards, fences, cameras)Customer data and data encryption
Hardware and serversIdentity and Access Management (IAM)
Network infrastructure (routers, switches, cables)Operating system patching (for EC2)
Virtualisation layerApplication-level security
Global infrastructure (Regions, AZs, Edge Locations)Network and firewall configuration (Security Groups, NACLs)
Managed service software (RDS OS, Lambda runtime)Client-side and server-side encryption choices
Key insight: The level of customer responsibility increases as you move from SaaS → PaaS → IaaS. With EC2 (IaaS) you patch the OS. With RDS (PaaS) AWS patches the DB engine. With S3 (SaaS-like) AWS manages everything except your data and access policies.

⚙️ Core AWS Services

Compute

ServiceTypeUse Case
EC2Virtual machinesFull OS control. Many instance families: t (burstable/dev), m (general), c (compute), r (memory), p (GPU/ML). Choose on-demand, reserved, or spot.
LambdaServerless functionsRun code without servers. Event-driven. Pay per 1ms execution. Auto-scales to zero. Max 15 min timeout.
ECS / EKSContainer orchestrationECS = AWS-native containers. EKS = Kubernetes on AWS. Both run on EC2 or Fargate (serverless containers).
Elastic BeanstalkPaaS deploymentUpload code, Beanstalk handles infra. Good for developers who don't want to manage EC2 directly.
LightsailSimple VPSSimplified, predictable pricing. For small websites, blogs, dev environments.

Storage

ServiceStorage Classes / VariantsUse Case
S3 (Simple Storage Service)Standard, Standard-IA, One Zone-IA, Glacier Instant, Glacier Flexible, Glacier Deep Archive, Intelligent-TieringObject storage for everything. Infinite scalability. 99.999999999% (11 nines) durability.
EBS (Elastic Block Store)gp3 (general), io2 (high IOPS), st1 (throughput), sc1 (cold)Block storage attached to EC2. Like a hard drive. Stays in one AZ.
EFS (Elastic File System)Standard, IA tiersManaged NFS. Multiple EC2 instances can mount simultaneously. Automatically scales.
S3 GlacierInstant / Flexible / Deep ArchiveLong-term archival. Deep Archive = cheapest storage in AWS, retrieval takes hours.

Databases

ServiceTypeKey Points
RDSRelational (managed)MySQL, PostgreSQL, Oracle, SQL Server, MariaDB. Automated backups, Multi-AZ HA, read replicas.
AuroraRelational (AWS-native)MySQL/PostgreSQL compatible. Up to 5× faster than MySQL. 6 copies across 3 AZs. Serverless option available.
DynamoDBNoSQL key-value / documentSingle-digit ms latency at any scale. Serverless. Global Tables for multi-region. DAX for in-memory caching.
ElastiCacheIn-memory cacheRedis or Memcached. Sub-ms latency. Session stores, leaderboards, real-time analytics.
RedshiftData warehousePetabyte-scale analytics. Columnar storage. Integrates with S3 via Redshift Spectrum.

Networking

ServicePurpose
VPCVirtual private network in AWS. Define subnets (public/private), route tables, Internet Gateway, NAT Gateway.
Security GroupsStateful virtual firewall at the instance level. Default: deny all inbound, allow all outbound.
NACLsStateless firewall at the subnet level. Must define both inbound and outbound rules explicitly.
Route 53Scalable DNS service. Domain registration, health checks, routing policies (simple, weighted, latency, failover, geolocation).
CloudFrontCDN. Cache content at 400+ Edge Locations. Integrates with S3, EC2, ALB. DDoS protection via Shield.
ELB — ALBApplication Load Balancer. Layer 7. Routes based on URL path, host headers, HTTP method.
ELB — NLBNetwork Load Balancer. Layer 4 (TCP/UDP). Millions of requests/sec, ultra-low latency.
Direct ConnectDedicated private connection from on-premises to AWS. Not over internet. More reliable, predictable.

Security & Identity

ServicePurpose
IAMUsers, groups, roles, policies. Principle of least privilege. Roles for services and cross-account access. Never use root for daily work.
KMSKey Management Service. Create and control encryption keys. AWS-managed or customer-managed.
ShieldDDoS protection. Shield Standard = free, automatic. Shield Advanced = paid, 24/7 DRT support, financial protection.
WAFWeb Application Firewall. Protect against SQLi, XSS, bad bots. Works with CloudFront, ALB, API Gateway.
GuardDutyThreat detection using ML. Analyses VPC flow logs, DNS logs, CloudTrail events. No agents needed.
InspectorAutomated vulnerability scanning for EC2, Lambda, container images.
MacieDiscover and protect sensitive data in S3. ML-powered PII detection.
Secrets ManagerSecurely store and auto-rotate credentials, API keys, database passwords.

🏗️ AWS Well-Architected Framework — 6 Pillars

🔧 Operational Excellence
Run and monitor systems. Automate changes. Respond to events. Improve operations continuously. IaC, runbooks, game days.
🔐 Security
Protect information, systems, assets. IAM, encryption at rest/transit, detective controls, incident response automation.
💪 Reliability
Recover from disruptions. Scale dynamically. Multi-AZ, multi-region, auto-scaling, backups, chaos engineering.
⚡ Performance Efficiency
Use resources efficiently. Serverless, right-sizing, caching (CloudFront, ElastiCache), global distribution.
💵 Cost Optimisation
Avoid unnecessary cost. Reserved/Spot, right-sizing, Cost Explorer, Trusted Advisor, delete idle resources.
🌱 Sustainability
Minimise environmental impact. Serverless, managed services, efficient instance types, shut down unused resources.
