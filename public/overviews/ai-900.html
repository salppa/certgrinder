🧠 AI / ML Hierarchy

🤖 Artificial Intelligence (AI)
Machines that simulate human intelligence and decision-making
📊 Machine Learning (ML)
Learn patterns from data without explicit programming
🧬 Deep Learning (DL)
Multi-layer neural networks. Learns complex representations. Powers vision and NLP at scale.

📊 Machine Learning Types

Supervised Learning
Train on labelled data. Model learns input→output mapping.

Regression: predict numeric values (house price, temperature).
Classification: predict categories (spam/not spam, disease/healthy).
Unsupervised Learning
Train on unlabelled data. Model finds hidden structure.

Clustering: group similar items (customer segmentation).
Dimensionality Reduction: compress data while preserving information.
Reinforcement Learning
Agent learns by trial-and-error in an environment. Reward for good actions, penalty for bad. Used in games, robotics, autonomous systems.
Anomaly Detection
Identify unusual patterns that don't conform to expected behaviour. Fraud detection, equipment failure prediction, network intrusion.
Regression vs Classification: Regression predicts a NUMBER (salary = $52,000). Classification predicts a CATEGORY (salary tier = "mid-range"). This distinction appears frequently in exam questions.

🎤 Azure AI Speech Services

Speech to Text
Real-time or batch transcription. Custom models for domain-specific vocabulary (medical, legal). Speaker diarisation.
Text to Speech
Natural-sounding voices. 400+ voices in 140+ languages. Custom Neural Voice — create your own brand voice.
Speech Translation
Real-time spoken language translation. Input speech → output speech or text in another language.
Speaker Recognition
Verify or identify speakers from audio. Speaker verification (is this person who they claim?) and identification (who is speaking?).

🤖 Generative AI (15-20% of exam)

Large Language Models (LLMs)
Trained on vast text. Predict next token. Emergent capabilities: reasoning, summarisation, code generation, translation. GPT-4, Claude, Llama.
Prompt Engineering
Craft inputs to guide model outputs. Zero-shot, few-shot, chain-of-thought prompting. Grounding with context reduces hallucinations.
Retrieval Augmented Generation (RAG)
Augment LLM with external knowledge retrieval. Reduces hallucinations. Azure AI Search + Azure OpenAI is a common RAG architecture.
Copilots
AI assistants embedded in applications. Microsoft Copilot in M365, Dynamics, GitHub, Azure. Built on Azure OpenAI + Microsoft Graph.

⚖️ Responsible AI — Microsoft's 6 Principles

⚖️ Fairness
AI systems should treat all people fairly. Avoid bias based on gender, race, age, etc. Fairlearn toolkit for bias detection.
🔒 Reliability & Safety
Behave as designed. Handle errors safely. Extensive testing, monitoring, fallback mechanisms. Critical for autonomous systems.
🛡️ Privacy & Security
Respect data privacy. Protect personal data used in training and inference. Differential privacy, secure data handling.
🌍 Inclusiveness
AI should empower everyone, including people with disabilities. Design for diverse users. Accessibility as a first-class requirement.
🔍 Transparency
AI systems should be understandable. Explainable AI (XAI). Interpretability ML tools. Users should know they are interacting with AI.
📋 Accountability
Humans remain responsible for AI systems. Governance, audits, human-in-the-loop for high-stakes decisions. AI should not replace human accountability.
Exam tip — Responsible AI mnemonic: Fair Reliable Private Inclusive Transparent Accountable — "For Responsible Practice, Include Transparent Accountability"
